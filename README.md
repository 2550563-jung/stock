# 모의 증권거래소 (멀티플레이 주식 게임)

가상 기업 8개 종목을 여러 플레이어가 **같은 호가창**에서 실시간으로 거래하는 웹 게임입니다.
백엔드는 Supabase(Postgres)이고, 주문 매칭·잔고·시세 변동을 모두 DB 함수가 처리합니다.
그래서 브라우저에서 값을 조작해도 결과가 바뀌지 않습니다.

## 특징

| 구분 | 내용 |
|---|---|
| 주문 매칭 | 지정가/시장가, 가격 우선 → 시간 우선, 부분 체결, 자기매매 방지 |
| 한국장 규칙 | 호가 단위(2023년 개편 기준 1~1,000원), 가격제한폭 ±30%, 거래일 단위 장 시작/마감, 장 마감 시 미체결 주문 소멸 |
| 비용 | 매매수수료 0.015%(매수·매도), 매도 거래세 0.20% — **게임용 설정값**이며 실제 세율과 다를 수 있음 |
| 시세 | 적정가 랜덤워크 + 종목/시장 뉴스 이벤트 + 시장조성 봇(5단계 호가) + 노이즈 트레이더 봇. 플레이어 대량 주문은 적정가에 수급 충격을 줌 |
| 멀티플레이 | 상시 **메인 시장**(무기한, 계좌 초기화 가능) + **방 만들기**(시작자금·하루 장 시간·거래일 수·인원 설정, 코드 초대, 종료 시 순위) |
| 계정 | 닉네임만으로 게스트 시작 또는 닉네임+비밀번호 가입. 게스트는 나중에 비밀번호 설정 가능 |
| 기타 | 실시간 뉴스·채팅(Supabase Realtime), 분봉/일봉 차트, 순위표 |

### 실제 주식과 다른 점 (단순화)
- 동시호가(장 시작·마감 단일가 매매), 변동성완화장치(VI), T+2 결제, 공매도·신용거래 없음
- 하루 장(09:00~15:30)을 설정한 초(메인 시장은 300초)로 압축
- 종목은 모두 가상 기업(실존 기업과 무관하게 지은 이름)

## 구조

```
supabase/migrations/   DB 스키마·함수 (순서대로 실행)
  ..01_st_schema.sql     테이블 + RLS
  ..02_st_helpers.sql    호가단위·상하한가·수수료 헬퍼
  ..03_st_engine.sql     매칭 엔진, 장 시작/마감, 시세 시뮬레이션
  ..04_st_api.sql        로그인·방·주문·조회 RPC + 실행 권한
  ..05_st_cron_seed.sql  pg_cron 스케줄(2초 틱, 5분 정리) + 메인 시장 생성
web/                   정적 웹 클라이언트 (index.html, app.js, style.css, config.js)
```

모든 DB 객체는 `st_` 접두어를 사용해 같은 프로젝트의 다른 앱 테이블과 섞이지 않습니다.

## 실행

DB는 Supabase 프로젝트에 이미 적용되어 있고, pg_cron 이 2초마다 시장을 움직입니다.
(새 프로젝트에 설치할 때만 `supabase/migrations/` 파일을 번호 순서대로 SQL Editor 에서 실행)

**플레이 주소: https://2550563-jung.github.io/stock/** (GitHub Pages, `gh-pages` 브랜치)

`web/` 을 수정한 뒤 다시 배포하려면:
```bash
git subtree split --prefix web -b gh-pages-new && git push -f origin gh-pages-new:gh-pages && git branch -D gh-pages-new
```

## 보안 메모
- 테이블은 모두 RLS 활성화. 시세·체결·뉴스·채팅만 공개 조회 가능하고, 적정가(`st_stock_sim`)·계좌·주문은 비공개입니다.
- 쓰기는 `security definer` RPC로만 가능하며, 세션 토큰은 SHA-256 해시로 저장하고 비밀번호는 bcrypt로 저장합니다.
- 로그인 실패 10회/10분 제한이 있습니다.
